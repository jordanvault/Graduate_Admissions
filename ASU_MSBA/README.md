## 확인됨 (검색 결과 기준)
- 2027 가을 입학은 **rolling 심사, 마감 2027-07-15** (유학생은 비자 일정 때문에 훨씬 일찍 내는 게 유리 — 미확인, 문의 필요)
- 결정 통보: 서류 완비 후 약 3주
- 이력서: 직책·재직 기간을 **월/연(MM/YYYY)** 형식으로 명시
- 에세이: 배경·목표를 묻는 **짧은 에세이 문항**이 포털에 있음. **Personal statement는 받지 않으며 제출 시 심사 지연**
- 입학 후 enrollment deposit 필요

## 포털에서 확인됨 (본인이 붙여넣은 지원서 첫 화면 기준)
- 캠퍼스: **Tempe(대면) / Online** 두 가지. F-1 유학생은 Tempe(대면)가 해당
- 입학 전 **필수 orientation**, F-1/J-1은 별도 international student orientation 필수
- **선택 전공(specialization)은 Tempe 한정**, 선택 시 **필수 3번째 학기 추가 → 최소 15개월**
- 포털 질문: "Do you plan to complete a third semester track?" (필수 선택), 추천인 소개(alumni/faculty, 선택)
- **추천서 1부만 필요**: 이름, 소속, **회사 이메일**. gmail/hotmail/yahoo 등 개인 메일 추천서는 **거부될 수 있음**. 가족·친구 비권장
- 업로드 서류는 지원서에 바로 포함. **공식 성적증명서는 합격 후** ASU Graduate Admission Services로 발송
- 제출 후 My ASU 계정 발급, 체크리스트에서 서류 수령 상태 확인
- 이 화면에는 에세이·GMAT/GRE·지원비 항목이 보이지 않음 → 뒤 단계 화면에서 확인 필요
