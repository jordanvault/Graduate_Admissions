## 인포세션 슬라이드 요약 (업로드된 캡처 8장 기준)
| 슬라이드 | 핵심 내용 |
|---|---|
| Ideal Applicant | Analytical Curiosity / Academic Readiness / Problem-Solving Ability / Communication Skills / Career Vision. 에세이·이력서·면접에서 이 5가지를 각각 증명할 것 |
| MSBA Framework | 기술·분석 역량(기술 스킬셋 확장, 비즈니스 이해)과 경영·커뮤니케이션 역량(비판적 사고, 리더십·팀워크·소통)을 결합. 목표는 data-driven decision making |
| Analytics in a Nutshell | 보고(What happened) → 분석(Why, 예: 가격 탄력성) → 예측(What will happen) → 전략 제안(What should we do, 예: 가격 설정). 복잡도·가치가 높은 쪽이 목표 |
| Foster Competitive Edge | 기술 역량 + 비즈니스 감각 + 조직 안에서 일을 되게 하는 능력 |
| Foster School Lens | Faculty Director Amin Sayedi: "비즈니스 질문에서 출발해 적합한 분석 도구를 찾는다." 방법론 자체가 목적이 아님 |
| 리더십 강조 | 리더십, 전략적 사고, 기업가정신. 복잡하고 비정형인 실제 문제를 해결하는 학생상 |
| 2027 Class Profile | 주요 전공: Economics, Engineering, Math, Business, Information Systems. 국가: 한국 포함 다수. 직무: Logistics Associate, International Trade Specialist, Consultant 등. 기업: Deloitte, EY, Boeing, Microsoft, Oracle, T-Mobile 등 |
| Built Through Community | 팀 프로젝트, 다양한 코호트, 학생 주도 활동·클럽, 동문·산업 네트워킹 |

## 에세이에 주는 시사점
- **Foster의 렌즈는 "비즈니스 질문 먼저, 도구는 나중"** → 본인의 Samsung SDS 사례(숫자 대조가 아니라 정의·규칙 표준화로 문제를 재정의)와 잘 맞음. 에세이의 중심 서사로 사용.
- **Analytics in a Nutshell 사다리**: 본인 경험은 보고·모니터링(SQL 모니터링 도구) → 분석(SDS 스냅샷 분석) → 예측(COVID 회복 모델) 단계. 부족한 것은 예측·처방(전략 제안) 단계의 정식 훈련이라는 논리로 연결.
- **Ideal Applicant 5요소**와 본인 근거 매핑은 `essays/analytical_preparedness.md` 하단 표 참고.
- 학급 구성에 물류·무역 직무와 한국 출신이 있어 물류/공급망 커리어 목표가 어색하지 않음.
